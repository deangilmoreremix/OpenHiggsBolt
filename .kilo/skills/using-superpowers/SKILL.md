Use when starting any conversation to establish proper skill usage.

Rules:
1. **Skill first** — Invoke Skill tool BEFORE any response when a skill applies
2. **Find the right skill** — Match the situation to an available skill
3. **Apply fully** — Follow the skill's instructions completely
4. **Verify** — Confirm the skill was applied correctly

Available skill categories:
- **Debugging**: systematic-debugging, root-cause-tracing, condition-based-waiting
- **Implementation**: think-before-coding, simplicity-first, tdd, goal-driven-execution
- **Planning**: brainstorming, writing-plans, executing-plans, verification-before-completion
- **Review**: code-review, receiving-code-review
- **Advanced**: git-worktrees, subagent-driven-development, dispatching-parallel-agents

When in doubt, use `brainstorming` to explore the problem space first.
