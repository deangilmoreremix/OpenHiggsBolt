---
name: distill-ui
description: Strip interface to essence, remove complexity and bloat
---

Use when UI feels complex or overwhelming.

Process:
1. **Identify core action** — What is the user's primary goal?
2. **Remove secondary paths** — Hide or defer non-essential options
3. **Consolidate similar actions** — One way to do each thing
4. **Simplify language** — Remove jargon, clarify intent
5. **Reduce visual noise** — Fewer colors, less decoration, clearer hierarchy
6. **Progressive disclosure** — Advanced features hidden behind interaction

Result: Interface that guides users directly to their goal without confusion.
