---
name: goal-driven-execution
description: Define verifiable success criteria before implementing
---

Transform tasks into goals with explicit success criteria.

Process:
1. **Define the goal** — What does success look like? How can it be verified?
2. **Make criteria measurable** — "Works" is not enough; define concrete outcomes
3. **Build verification loops** — Check progress toward goal continuously
4. **Report status** — Show how close you are to meeting criteria

Examples of good goals:
- "All 15 tests in `user.test.js` pass" (verifiable)
- "Component renders without error in Chrome" (measurable)
- "API returns 200 status for valid input" (testable)

Examples of poor goals:
- "Make the UI better" (vague)
- "Fix the bug" (doesn't define what fixed looks like)
