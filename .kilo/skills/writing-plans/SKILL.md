name: writing-plans
description: Create bite-sized tasks (2-5 min each) before touching code
---

When you have clear requirements or a spec, use this skill to create an execution plan.

1. **Decompose** — Break work into tasks that take 2-5 minutes each
2. **Prioritize** — Order by dependency or impact
3. **Track with TodoWrite** — Add all tasks to your todo list
4. **Emphasize TDD** — Write tests alongside implementation tasks
5. **Apply DRY/YAGNI** — Remove duplication, don't add speculative features

Example task format:
- "Add login form validation" (not "Build auth system")
- "Write test for user registration"
- "Create user profile API endpoint"
- "Add error handling for network failures"

Plans should be actionable immediately — each task is a complete, testable unit of work.
