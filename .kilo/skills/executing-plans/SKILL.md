After a plan is written and approved, use this skill to execute it.

Process:
1. **Review the plan** — Read each task, understand its goal, identify dependencies
2. **Execute in order** — Complete tasks sequentially, marking them done
3. **Test continuously** — Run tests after each logical change
4. **Verify completion** — All tasks done, all tests pass
5. **Finish the branch** — Clean up, prepare for merge or next steps

If you discover issues while executing:
- Update the plan to reflect reality
- Don't skip verification steps
- Keep changes focused to the task at hand

The plan is your contract with the user — fulfill it completely, or renegotiate.
