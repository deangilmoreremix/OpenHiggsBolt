---
name: brainstorming
description: Explore requirements and design before implementation
---

Use before any creative or implementation work. The goal is to align on requirements and design before code.

Steps:
1. **Clarify user intent** — What problem are we solving? Who benefits?
2. **Identify constraints** — Technical limits, user needs, business requirements
3. **Generate options** — Multiple approaches, not just one
4. **Evaluate trade-offs** — Pros/cons of each option
5. **Select direction** — Pick one, document rationale

Hard gate: no code until design is explicitly approved. Changing code is more expensive than changing ideas.
