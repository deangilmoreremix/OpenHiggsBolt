---
name: delight-ui
description: Add personality and memorable touches to interfaces
---

Use when UI feels generic or needs memorable moments.

Guidelines:
- **Purposeful delight** — Animation, micro-interaction, or visual flourish that aids comprehension
- **Not decoration** — Every delight serves functional purpose
- **Subtle character** — A unique hover state, custom cursor, or loading sequence
- **On-brand** — Personality matches product tone and audience
- **Performance** — Delight doesn't block or slow the core flow

Examples:
- Custom cursor that reacts to hoverable elements
- Loading indicator that reflects brand character
- Micro-interaction when adding items to cart
- Subtle sound on successful action (only if appropriate)

Add one delight at a time. Verify it enhances, not distracts.
