---

Use when designing first-use experiences.

Elements to design:
- **Empty states** — Helpful messaging when no data exists
- **Welcome flow** — First steps, permissions, setup
- **Activation triggers** — Clear path to value proposition
- **Progressive tips** — Contextual guidance without nagging
- **Success states** — Celebration for completed actions

Principles:
- Don't overwhelm on first visit
- Show value immediately
- Make skip/decline easy
- Provide next steps clearly
- Match brand tone exactly
