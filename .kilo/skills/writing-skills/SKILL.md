---
name: writing-skills
description: Create or verify skills before deployment
---

Use when creating or editing skills, or before deploying a skill for others to use.

Process:
1. Define the trigger conditions — when should this skill be used?
2. Write the instructions — clear, actionable steps
3. Include examples — concrete scenarios showing skill in action
4. Add verification steps — how to confirm the skill worked correctly
5. Test the skill — apply it to a real problem and validate output

Keep skills focused on a single purpose. Avoid overlapping or merged responsibilities. Each skill should be independently useful and clearly differentiated from others.
