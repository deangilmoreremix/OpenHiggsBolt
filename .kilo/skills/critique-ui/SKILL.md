Use when reviewing UI for user experience quality.

Scoring framework (0-10 scale):
- **P0 (fatal)** — Makes the product unusable or feels broken
- **P1 (major)** — Significantly hurts UX, obvious fix needed
- **P2 (moderate)** — Noticeable but not blocking issues
- **P3 (minor)** — Polish-level refinements

Review areas:
1. **Visual hierarchy** — Typography, spacing, contrast direct attention
2. **Information architecture** — Content grouping, navigation, labels
3. **Cognitive load** — Is the next step obvious?
4. **Interaction patterns** — Consistent, predictable, accessible
5. **Edge cases** — Empty states, errors, loading states handled
