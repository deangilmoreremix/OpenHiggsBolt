---
name: colorize-ui
description: Add strategic color to monochromatic interfaces
---

Use when UI feels flat or colorless.

Color strategy (pick one):
- **Restrained** — Tinted neutrals + one accent ≤10%
- **Committed** — One saturated color on 30-60% of surface
- **Full palette** — 3-4 named roles used deliberately
- **Drenched** — Surface IS the color (heroes, campaigns)

Process:
1. **Analyze current palette** — Check for cream/sand tells, warm-neutral defaults
2. **Pick strategy** — Match to brand intent and user context
3. **Apply systematically** — Use OKLCH, maintain contrast ≥4.5:1
4. **Verify** — All states (hover, focus, disabled) colored appropriately
5. **Add motion** — Color transitions should be smooth
