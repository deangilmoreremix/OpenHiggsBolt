name: init-project
description: Set up project context with PRODUCT.md, DESIGN.md, and conventions
---

Use when starting work on a new frontend project or feature.

Setup sequence:
1. **Gather context** — Check for existing PRODUCT.md, DESIGN.md, style guide
2. **If missing PRODUCT.md** — Create it: what this app does, who it's for, key features
3. **If missing DESIGN.md** — Document current visual system: colors, typography, spacing
4. **Identify conventions** — CSS methodology, component patterns, naming
5. **Set up tools** — Linting, formatting, testing infrastructure
6. **Define next steps** — Prioritized tasks for immediate work

Output: Clear understanding of project goals, design constraints, and next actions.
