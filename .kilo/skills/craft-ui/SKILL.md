---
name: craft-ui
description: Shape and build frontend features end-to-end with production-grade code
---

Use when building a new frontend feature from scratch.

Workflow:
1. **Context gathering** — Read PRODUCT.md, DESIGN.md, existing components
2. **Design decision** — Choose color strategy (restrained/committed/full/drenched), typography, spacing
3. **Implementation** — Write production code, not prototypes
4. **Verify** — Test in browser, check all breakpoints, accessibility
5. **Polish** — Final alignment, interaction, and motion

Produce complete, tested, responsive components. Use existing design system when present. Write code that could ship today.
