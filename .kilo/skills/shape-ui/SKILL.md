---
name: shape-ui
description: Plan UX/UI design before writing code for a feature
---

Use when planning a UI feature or component.

Planning steps:
1. **State assumptions** — What is the user goal? What constraints exist?
2. **Explore alternatives** — 3+ different approaches, pros/cons each
3. **Choose direction** — Select one, document rationale
4. **Define structure** — Component hierarchy, state flow, props
5. **Specify details** — Colors, typography, spacing, motion
6. **Get approval** — Confirm with user before coding begins

Hard gate: no code until design is approved. This prevents wasted implementation effort.
