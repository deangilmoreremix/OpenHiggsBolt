## The parameterisation — per-design deviation record

All four upstreams hardcode **every** string, colour and dimension in JSX and have **no props
surface at all**, so they are unbrandable without editing the file. This is the scoped deviation
A6's contract addition **C8** allows for repo 2. The rule A8 applied:

- change **only** a hard-coded literal → a prop whose **default equals the original literal**;
- add the prop to the component's props type with that default;
- keep the animation logic, the springs, the easing and the layout **byte-identical**;
- record the change in the file's own provenance header.

## Licence / attribution — repo 2's unusual position

`remotion-templates` ships **no `LICENSE` file** and names **no copyright holder**. Its README
says: *"All templates in this repository are available under the MIT License. You can use them in
personal and commercial projects, but attribution is appreciated where applicable."* Every
template file carries the in-file header *"Free Remotion Template Component … This template is
free to use in your projects! Credit appreciated but not required. Created by the team at
https://www.reactvideoeditor.com"*.

Per A6's contract addition **C10**:

- `source.license` = `'MIT'`;
- `source.attribution` = **exactly**
  `Remotion templates by React Video Editor (reactvideoeditor.com) — MIT License.`
- `source.repository` = `'remotion-templates'`;
- `source.repositoryUrl` = `'https://github.com/deangilmoreremix/remotion-templates'`;
- `source.sourcePath` = the path relative to the repo root, e.g. `templates/animated-text.tsx`.

**The credit line drawn inside the design** (A6's dual credit-line rule) carries **three** parts,
in `designs/rveSharedDesign.tsx`:

1. `RVE_ATTRIBUTION` — the same string as `source.attribution`;
2. `RVE_UPSTREAM_CREDIT` — the upstream's own in-file credit, verbatim, preserving the
   *"Credit appreciated but not required"* intent;
3. `RVE_LICENSE_NOTICE` — the **verbatim MIT permission notice WITHOUT a copyright line**
   (there is no holder to name).

The Phase 1 credit in `designs/shared.tsx` names **RenderComp**, which is the wrong upstream for
these designs, so the repo-2 designs draw their **own** credit (`RveCreditBlock`) inside their own
stage (`RveDesignStage`, which mirrors `DesignStage` exactly — same DOM, same
`data-remotion-design` / `data-remotion-design-canvas` hooks, same composition-sized canvas
scaled into the design box, same "omit the transform when the box already is the composition"
rule). The test asserts the credit contains `React Video Editor`, `MIT License`,
`Credit appreciated but not required` and `Permission is hereby granted`, and that it contains
**neither** `Copyright (c)` **nor** `RenderComp`.

The MIT notice is set as **small print** (6 px) inside the design. A6 C10 asks A11 to aggregate
the distinct `source.attribution` values in the product's **credits surface**; that is the right
place for a full-size rendering of the notice. It travels in the design as well.

## Decisions

- **The repo-2 designs draw their OWN credit instead of using `DesignStage`** — the shared stage
  draws `© 2026 Trimora Inc. (RenderComp) · MIT`, which names the **wrong upstream** for a React
  Video Editor template. `RveDesignStage` mirrors `DesignStage` exactly (same DOM and data
  attributes, so the injected typography stylesheet and every consumer keep working) and swaps the
  credit. `designs/shared.tsx` is owned by another agent and was not touched.
- **The upstream copies get their own `RveDesignStage` instead of `DesignStage`** — the shared
  stage's credit is repo-1 specific (see above). The mirror is exact, so the canvas scaling, the
  clipping and the typography override behave identically.
- **The credit block carries the full MIT permission notice** — the brief requires the credit
  *drawn inside the design* to include the verbatim notice without a copyright line. It is set as
  6 px small print; the product's credits surface (A6 C10, A11) is where a full-size rendering
  belongs.
- **`rve-circular-progress` has no text slot** — the upstream's percentage is a time-driven loop
  (C8 / the brief: do **not** parameterise the progress value), and the upstream draws no other
  text. Adding a label would be a new element, not a literal → prop change. The design is
  brandable through its colours only; this is stated in its `capabilities.notes`.
- **Every upstream prop is optional with the upstream literal as its default** — so rendering the
  copy with **no props reproduces the upstream design verbatim** (pinned by a test).
- **The adapter never passes the upstream's `rem` size** — it passes a px value derived from the
  composition's **short edge**, which is 1080 px in all four supported formats, so one ratio reads
  the same everywhere (C9).
- **The headline is truncated against the composition width**, not with a fixed constant: the
  repo-2 templates centre their copy in a 100 %-wide container without `whiteSpace: "nowrap"`, so
  a long string wraps and overflows. The limit is
  `min(ceiling, floor(width × 0.88 / (fontSize × 0.62)))` — the scale cancels out, so it is the
  same at every placement scale.
- **Two dead bindings were removed from the upstream copies** (the unused `fps` destructure in
  `circular-progress`, the unused `interpolate` import in `popping-text`) so the new files add
  **zero** eslint findings. Both are listed in the deviation records and in the tables above.
- **The popping-text palette keeps three entries** — the upstream rotates it with
  `i % colors.length`, so the brand palette is rebuilt as a dark → mid → light ramp of the brand
  primary with the same count.
- **The popping-text family is the bundled deterministic stack** from `designs/fonts.ts`, not a new
  system-font stack (C11). The upstream's `Impact` is replaced deliberately and noted in the
  entry's `capabilities.notes`.
- **`placement.animation` is `'none'`** — the upstream templates animate themselves; a layer
  entrance animation on top would double the motion.
- **No `defaultProps`** on these entries — the repo-2 upstreams have no canvas-fill prop (they
  paint no background at all), and every copy/colour prop is brand-derived at render time, so the
  upstream demo strings (`"Hello Remotion"`, `"BINGO!"`, `"Sliding Text!"`) are never reachable.
  The tests assert exactly that.

- **`src/shared/personalization/templates/catalog.ts`** — A11 (the `catalog` lane) must import and
  register the four entries. The exact code is in *The registry entries for A11* above. A8 did
  **not** touch this file.
- **`src/shared/personalization/templates/catalog.ts` — the credits surface** — A6 C10 requires
  the product's credits surface to show **both** repository credits when a project uses designs
  from both. `getRemotionDesignAttributionLine()` currently returns one string (the repo-1
  RenderComp line). A11 must make it aggregate the distinct `source.attribution` values actually
  in use, i.e. it has to include
  `Remotion templates by React Video Editor (reactvideoeditor.com) — MIT License.`
  next to the existing repo-1 line. The repo-2 permission notice (**without** a copyright line)
  is exported as `RVE_LICENSE_NOTICE` from
  `src/shared/personalization/templates/designs/rveCatalogEntries.ts` for that surface.
- **`templates/types.ts` `RemotionDesignTextSlot.maxLength`** (A4's item 5) — A8 does **not**
  need it: the four entries declare no `maxLength` and the truncation is enforced in the adapter
  (the composition is not canvas-aware in the way the slot contract assumes). A11 still owns that
  change for the other designs.
- **Slot contract** — all four entries declare exactly one primary slot with
  `key: 'headline'`, `field: 'headline'`, `label: 'Headline'`, `primary: true`.
  `rve-circular-progress` declares **no** slots, so it has **no `layer.text`** — a design layer
  with no primary slot is legal (A4's §5.7) and the catalog's `applyDesignTemplate` already
  handles it (`text` stays `undefined`).
- **The new `designs/rveSharedDesign.tsx`** is a helper module, not a design: it exports no
  `RemotionDesignTemplate` and no id that could be registered. A11 must **not** add it to
  `REMOTION_DESIGN_TEMPLATES`.
