`brandTextValue()` is gone; `resolveDesignTextSlots()` now delegates to
`resolveDesignSlotValues(design, layer, brand)`. Precedence:

* primary slot → `layer.text` when it is a string (an empty string blanks the slot), else the brand

An absent / blank / malformed override therefore never renders empty as long as the brand has a
value. **The composition does not import from `guided/`** — the cycle
(Composition → OverlayEditor → Provider → Modal → OverlayEditor) is broken.

## 4. A5's two lint findings introduced by Phase 1

**`src/shared/personalization/DemoPersonalizeProvider.tsx:1344-1353`** — the registry list was a
`useMemo` keyed on a version counter, and the counter was never read inside the callback, so
`react-hooks/exhaustive-deps` flagged it as an unnecessary dependency. The fix is a **restructure,
not a suppression**: the version counter is gone and the registered list lives in state.

```tsx
  // The catalog registers itself on import, which can happen after this
  // provider mounted. The registered list therefore lives in STATE and is
  // re-derived from the registry whenever the registry announces a change.
  const [remotionDesignTemplates, setRemotionDesignTemplates] = useState<
    RemotionDesignTemplate[]
  >(() => listRemotionDesignTemplates())

  useEffect(
    () =>
      subscribeRemotionDesignRegistry(() =>
        setRemotionDesignTemplates(listRemotionDesignTemplates()),
      ),
    [],
  )
```

The behaviour is identical — the list is re-derived from the registry on every registry
notification — and the lint rule is satisfied because there is no longer a phantom dependency.

**`src/shared/personalization/preview/__tests__/designLayerComposition.test.tsx:28-32`** — a
targeted, single-line suppression inside the `vi.mock('remotion')` factory. The rule is **not**
disabled globally and **not** disabled for the file:

```tsx
    // It is a plain `<img>` on purpose — the rule is disabled for this ONE
```

### A10's residual — the badge monogram

`logo-stroke-draw/LogoStrokeDraw.tsx` rendered its monogram as an SVG `<text>` element. The in-browser
web renderer rasterises every `<svg>` by serialising it into a `data:image/svg+xml` document, and an
isolated document cannot load a document-level `@font-face` — so that one letter fell back to a
system face.

Fix (`L170-235`): the monogram is now an **HTML element** (`<div data-lsd-monogram>`) with the same
position (`left: cx`, `top: cy`), size (`fontSize: R * 1.15`), weight (`800`), colour
(`accentColor`), opacity (`fillIn`) and letter spacing (`-0.02em`) as the original SVG text, and the
same `scale(lockupScale)` about the badge centre. The shine sweep moved into a **second `<svg>`**
(L212-232) so it still paints **over** the monogram — the original z-order is preserved exactly.
The `lsd-shine-clip` id stays unique in the document.

## Decisions

- **The resolver lives in `preview/designSlots.ts`, not in `templates/`** — it needs
  `PreviewLayer` and `PreviewInputProps` (preview lane) as well as `RemotionDesignTextSlot`
  (templates lane), and `preview/` is the lane the composition already imports from. Every import
  in it is type-only, so it can never close a require cycle.
- **`applyDesignTemplate()` carries the overrides over only for the SAME design** — applying a
  different design replaces the layer, and the old design's slot keys would be meaningless (and
  would leak a stale value into a slot that means something else).
- **`normalizeTextSlotOverrides()` drops the non-string entries and returns `undefined` for an
  empty map** — an empty map and an absent map mean the same thing (every slot falls back to its
  brand field), so normalising them to the same value keeps the persisted settings canonical.
- **The `logo-reveal` monogram became an HTML element, and the shine sweep moved into a second
  `<svg>`** — a single `<svg>` with the monogram outside it would have changed the z-order (the
  sweep would no longer wash over the letter). The split keeps the original paint order exactly.
- **The `logo-reveal` monogram's HTML element uses `transform: translate(-50%, -50%) scale(s)`
  with `transform-origin: center center`** — the composition's `transform` order is
  `translate` applied after `scale`, and the percentages resolve against the untransformed border
  box, so the element's visual centre lands exactly on the badge centre `(cx, cy)`.
- **The credits surface aggregates the distinct attributions from the templates** rather than
  hard-coding the two lines — C10 asks for "the distinct `source.attribution` values actually in
  use", so a future third upstream surfaces automatically.
- **The A11 trigger classes for the eight flex-row studios are new** (the Video Studio one is the
  untouched original) — the nine studios A9 prepared had a trigger slot but no class, and the AI
  Influencer trigger needed an absolute class because its preview is a `relative` box with
  absolutely positioned buttons (A9's handoff §4).
- **A7's `catalog.test.tsx` assertions were rewritten rather than deleted** — the intent
  ("every design is well-formed, categories are covered, ids are unique, attribution is present")
  is now enforced for all 19 designs instead of only the Phase-1 five.
