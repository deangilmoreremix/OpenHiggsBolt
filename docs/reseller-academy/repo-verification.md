## Findings that differ from existing docs / assumptions

1. **Stack is not Supabase-centred.** 37/37 web apps are Next.js + NextAuth (Google OAuth) + Prisma + any PostgreSQL (`DATABASE_URL`, optional `DIRECT_URL`). Only `ai-headshot-studio` also reads `NEXT_PUBLIC_SUPABASE_*` / `SUPABASE_SERVICE_ROLE_KEY`. **0 apps ship Prisma or Supabase migrations**; their READMEs say to run `npx prisma db push`. `components/reseller/DeploymentCenter.jsx` currently tells customers to set `SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY` and apply "reviewed migrations" in a per-app schema — that does not match the app code. The Academy teaches the verified path (Supabase or Neon as the Postgres host → `DATABASE_URL`/`DIRECT_URL` → `prisma db push`). *Owner action: align the Deployment Center text (not changed here — out of scope).*
2. **Stripe model is one-time credit packs** (`mode: "payment"`, inline `price_data`, `checkout.session.completed`). For all 37 web apps **no Stripe Products or Price IDs need to be created** — pack names/credits/prices live in `src/lib/config.js` per app.
3. **Several apps contain two webhook routes** (e.g. `/api/stripe/webhook` and `/api/webhook/stripe`). Students register only the "recommended" path above (the one the README names, else a signature-verifying route).
4. **MuAPI key variable name differs per app** (`MUAPIAPP_API_KEY`, `MU_API_KEY`, `HEADSHOT_API_KEY`, `NANO_BANANA_API_KEY`, `SEEDANCE_V2_API_KEY`, `VEO31_API_KEY`, `AICLIPS_API_KEY`). Workshops use the exact name per app.
5. **`ai-youtube-shorts-generator` is a Python CLI** (requirements.txt + main.py): no Next.js app, no Stripe, no webhook, no Vercel path. Its workshop says so plainly; it cannot follow the SaaS launch path.
6. **`ai-resume-builder`**: no correct destination repo (the existing `deangilmoreremix/AI-Resume-Builder` is an unrelated fork). Facts come from upstream `SamurAIGPT/ai-resume-builder`. *Owner action: create/point a correct repo.*
7. **Upstream-derived facts:** the table shows which apps' destination repos are attribution-only. Where a destination repo has no LICENSE, redistribution rights are an owner decision.
8. **`oldphoto` demo returns HTTP 402** (Vercel-side); `ai-youtube-shorts-generator` has no demo; all others return 200. Links preserved unchanged.
9. **"Deploy on Vercel" button** is enabled only where `vercelDeploy: template` in `resellerDestinations.json`. Apps whose destination repo lacks source cannot be imported from it yet. *Owner action: publish source to those destination repos, then flip `vercelDeploy` to `template`.*
10. **All 76 reseller download artifacts are still `missing`** in `resellerAppBundles.json` (download route returns 503 `BUNDLE_NOT_AVAILABLE`). Owner action.
