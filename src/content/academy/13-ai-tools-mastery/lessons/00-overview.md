# AI Tools Mastery

This is a buyer's guide, not a set of tool tutorials. In four short guided lessons you learn which tool fits which creative outcome: image, video, voice and music, and where to run it all. You can follow along in SmartVideo GO AI's **Image Studio**, **Video Studio**, **Lip-Sync Studio**, **AI Influencer Studio** and **Storyboard / Campaign Planner**.

You need no prior experience. Do the lessons in order, because each one builds on the last.

| # | Lesson | Time | You will finish with |
|---|---|---|---|
| 1 | [Image Models — Which One for Which Use Case](01-image-models-which-one-for-which-use-case.md) | 15 min | An image model chosen per brief, with settings |
| 2 | [Video Models — Which One for Which Use Case](02-video-models-which-one-for-which-use-case.md) | 15 min | A video model, camera prompt and motion setting |
| 3 | [Voice/Audio Models — Which One for Which Use Case](03-voice-audio-models-which-one-for-which-use-case.md) | 15 min | An audio plan with voice, music, transcript and mix |
| 4 | [API vs. Local: A Decision Framework](04-api-vs-local-decision-framework.md) | 15 min | A cost payback calculation and hosting decision |
