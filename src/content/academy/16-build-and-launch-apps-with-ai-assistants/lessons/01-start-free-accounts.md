# Start your free accounts: Netlify, Clerk and Stripe

## Four accounts, four jobs

| Account | What it does for your app |
| --- | --- |
| GitHub | Stores your own copy of the app's code |
| Netlify | Builds the app from GitHub and puts it on the internet |
| Clerk | Handles people signing up and signing in |
| Stripe | Takes the payments (already built into the apps) |

All three services have a free plan at the time of writing. Limits and prices change, so read each pricing page before you rely on them.

## Steps

1. Sign in to GitHub (or create an account).
2. Create a Netlify account. Choosing sign-up with GitHub makes connecting your repo easier.
3. Create a Clerk account, then create an application named after your business with Email and Google sign-in.
4. Create or sign in to Stripe and **stay in test mode**.
5. Turn on two-step sign-in for each account.
6. Open each pricing page and write down the current free limits.

## Check yourself

You can open all four dashboards in separate tabs, and Stripe shows test mode.

## Common mistakes

* Skipping the pricing pages and hitting a limit later.
* Switching Stripe to live before a test purchase works.
