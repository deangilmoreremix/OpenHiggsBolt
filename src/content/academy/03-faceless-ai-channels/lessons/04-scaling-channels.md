# Scaling to Multiple Channels

> **Time:** about 14 minutes. **You will finish with:** a weekly batch calendar, isolated browser profiles for each channel, and a batch of five scripts with voice files.

---

## Before you start

One channel is a job; three channels is a system. Producing one video at a time takes about 2 hours, so three channels would take 6 hours a day and break your upload consistency. Temporal batching fixes this: write all 5 scripts on Monday, generate all 5 audio files on Tuesday, render clips on Wednesday, edit and schedule after that. This part sets up the calendar and profiles and runs the script and voice batch. Part 2 does visuals, editing and scheduling.

You will need: [`templates/production-schedule-tracker.md`](templates/production-schedule-tracker.md), your retention script template, a TTS tool such as ElevenLabs, and a browser such as Google Chrome.

## Step by step

### 1. Lock in your weekly calendar

Open [`templates/production-schedule-tracker.md`](templates/production-schedule-tracker.md) and set batch milestones: Monday scripting, Tuesday voiceovers, Wednesday visuals, Thursday editing, Friday scheduling. Never write a script on edit day.

**You should see:** a week with one task assigned to each day.

**If not:** if your week is different, keep the order (scripts, voices, visuals, edit, schedule) and move the days.

### 2. Create browser profiles per channel

If you run more than two channels, create a separate Google Chrome profile (or browser profile) for each channel identity and sign in to that channel's YouTube, affiliate dashboard and email in its own profile.

**You should see:** one profile per channel, each signed in to its own accounts.

**If not:** if you see the wrong channel in a profile, sign out there and sign in again with the right account.

### 3. Write the batch of scripts

In one block of time, write 5 scripts using your retention templates, each under 160 words. Do not do any other task during this block.

**You should see:** 5 finished scripts.

**If not:** if you are stuck on hooks, reuse the system prompt from lesson 1 for each topic.

### 4. Generate the voices in one run

Feed the scripts into ElevenLabs one after another and download the audio files into your organized project folders.

**You should see:** audio files for all 5 videos, named in order.

**If not:** if a voice sounds off, regenerate only that file.

## Check yourself

* [ ] My week has a fixed task for each day.
* [ ] Each channel has its own browser profile.
* [ ] I have 5 scripts and their audio files.
* [ ] I did not mix tasks during the batch.

## Common mistakes

* Switching between scripting, voice and editing multiple times a day.
* Sharing one browser profile across channels, causing login confusion.
* Writing a script on edit day.

## Go further

| Day | Task | Output | Hours |
|---|---|---|:---:|
| Monday | Scripting | 5 scripts (under 160 words each) | 1.5 |
| Tuesday | Voiceovers | 5 narration mp3s, silences trimmed | 0.5 |
| Wednesday | Visuals | 25 b-roll clips / screenshots | 2.0 |
| Thursday | Editing | 5 final 9:16 videos, captioned and graded | 1.5 |
| Friday | Scheduling | Scheduled across YouTube/TikTok/Instagram | 0.5 |

Result: 5 videos a week across 3 platforms (15 posts) in 6 hours. Video file: [templates/examples/faceless-workstation-clip.mp4](templates/examples/faceless-workstation-clip.mp4).
