# AI Agents & Vibe-Coding for Creators

> **Time:** about 77 minutes in total across 5 short lessons. **You will finish with:** a working micro-tool and a live sales page for it.

---

## Before you start

Coding agents such as Claude Code and Cursor removed the "you must already be a developer" barrier. This track teaches you to build and sell your own micro-tools, not just AI-generated media. You describe what you want in plain English and the agent writes, runs and fixes the code. Each lesson is a short guided walk-through; do them in order.
